# Git / GitHub Bootcamp Exercises

UdemyのGit/GitHub講座で学習した内容を、セクションごとに整理するためのリポジトリです。

## 学習目的

- Gitの基本操作を理解する
- ブランチ作成・マージ・コンフリクト解消を練習する
- GitHubでのPull Request運用を理解する
- 実務を意識したコミット単位やブランチ運用を身につける

## 学習内容

- git add / commit / status / log
- branch / switch / merge
- conflict resolution
- push / pull / fetch
- GitHub Flow
- Pull Request
